Herdr App（macOS 桌面版）繁體中文化 is an unofficial Traditional Chinese localization package for the Herdr App desktop application (herdr-app), version 0.1.16, on Apple Silicon macOS only. It is not a localization of the herdr terminal client or the herdr-core/hc command-line tools.

Upstream Herdr: https://github.com/herdrdev/herdr-app

The payload contains modified Herdr JavaScript UI resources and version-specific binary patch fragments. Changes include Traditional Chinese display strings and metadata references required to load those strings. The installer adds localized permission descriptions and signs the modified local copy.
